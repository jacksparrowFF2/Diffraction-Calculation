# 非周期相位层后续优化思路

本文档用于记录 `OptimizeMultiRadiusPhaseIslands.m` 之后的优化路线，供后续对话、代码修改和 DOE 设计引用。

## 1. 当前优化阶段

当前阶段只优化多半径圆形高折微岛的平面分布，固定以下物理参数：

```text
相位机制：反射光双程相位
高折材料 n_high = 1.75
低折材料 n_low = 1.55
折射率差 delta_n = 0.20
微岛高度 phaseHeight = 220 nm
微岛形状：圆形
高度类型：二值高度，微岛区域为 220 nm，其余为 0
```

当前优化变量为：

```text
RadiusSet_um：圆形微岛半径集合
TargetFillFactor：目标填充率
MinDistanceFactor：泊松盘最小中心距系数
Seed：随机种子
```

当前采用 DOE 粗扫 + 多 seed 重复，而不是直接使用复杂优化算法。这样做的原因是：随机非周期图案存在 seed 波动，先用 DOE 找稳定参数窗口，比过早上优化算法更稳。

## 2. 当前目标函数

优化目标是：

```text
衍射效果最不明显 + haze 风险受限
```

当前目标函数为：

```matlab
Objective = TopKPeakRatio ...
    + weightPeakBackground * PeakBackgroundRatioPenalty ...
    + weightHazePenalty * HazeRiskPenalty;
```

其中：

```text
TopKPeakRatio：
有相位层前 K 个局部峰平均强度 / 无相位层前 K 个局部峰平均强度。
数值越小，说明削峰越明显。

PeakBackgroundRatioPenalty：
有相位层峰值/背景比 相对于 无相位层峰值/背景比 的比例。
数值越小，说明衍射峰相对于背景不那么突出。

HazeRisk：
2.5° 角度范围外的能量比例。
用于近似 haze 或宽角散射风险。

HazeRiskPenalty：
当 HazeRisk 超过 hazeRiskLimit 时才产生惩罚。
```

当前 haze 上限不是固定绝对值，而是基于无相位层基准定义：

```matlab
hazeRiskLimit = baselineHazeMean * hazeLimitMultiplier;
```

当前 quick DOE 中：

```text
baselineHazeMean ≈ 0.0886
hazeLimitMultiplier = 1.20
hazeRiskLimit ≈ 0.1064
```

## 3. 如何判断最优设计

`OptimizeMultiRadiusPhaseIslands.m` 会将 DOE 结果按 `Objective` 升序排序：

```matlab
results = sortrows(results, 'Objective', 'ascend');
```

因此：

```text
CSV 第一行 = 当前目标函数下的最优候选；
Objective 越小 = 综合目标越好；
但仍需检查 HazeRisk 是否超过 hazeRiskLimit。
```

如果某个方案 `TopKPeakRatio` 很低，但 `HazeRisk` 明显超限，则说明它属于“削峰强，但 haze 风险偏高”的方案。后续需要在削峰和 haze 风险之间找 Pareto 折中。

## 4. 第一阶段：多半径圆形微岛 DOE

推荐先完成以下 DOE：

```text
radiusSet:
[1.0, 1.5] um
[0.8, 1.2, 1.8] um
[0.8, 1.2, 1.6, 2.0] um
[0.6, 1.0, 1.4, 1.8] um
[0.8, 1.0, 1.4, 1.8, 2.2] um

fillFactor:
0.30 / 0.35 / 0.40 / 0.45

minDistanceFactor:
1.0 / 1.2 / 1.5

seed:
1:10
```

分析方式：

```text
1. 先按 Objective 排序；
2. 再筛选 HazeRisk <= hazeRiskLimit 或接近 hazeRiskLimit 的候选；
3. 对同一组 radiusSet/fillFactor/minDistanceFactor 统计 seed 平均值和最差值；
4. 找出削峰稳定、haze 风险不过高的参数窗口；
5. 将候选参数导入 CustomApertureWithPhase_fraunhofer_fft.m 做 Figure 7/8/9 可视化复核。
```

## 5. 第二阶段：目标函数改进

当前目标函数仍较粗糙，后续可以增强为：

```text
TopKPeakRatio：
继续保留，用于削弱最强峰。

PeakBackgroundRatioPenalty：
继续保留，用于避免峰值相对背景过突出。

HazeRisk：
从软惩罚改为硬约束或 Pareto 筛选。

RGBSeparationPenalty：
加入 RGB 峰位分离惩罚，重点针对彩虹纹和彩点可见度。

NewPeakPenalty：
惩罚相位层引入的新尖锐峰。

SpectralFlatnessPenalty：
惩罚远场或相位图频谱中过强的规则空间频率。
```

一个后续更完整的目标函数可以写成：

```matlab
Objective = w1 * TopKPeakRatio ...
    + w2 * PeakBackgroundRatioPenalty ...
    + w3 * RGBSeparationPenalty ...
    + w4 * NewPeakPenalty ...
    + w5 * HazeRiskPenalty;
```

## 6. 第三阶段：从圆形多半径扩展到多高度

在多半径圆形微岛参数窗口稳定后，再引入多高度：

```text
heightSet:
[150, 220] nm
[150, 200, 250] nm
[100, 150, 200, 250] nm
```

多高度的意义：

```text
增加相位自由度；
降低二值相位带来的固定频谱特征；
有机会在削峰相同的情况下降低 haze 风险；
更接近灰阶压印或灰阶光刻设计。
```

需要注意：多高度会增加制程复杂度，因此应同时记录高度级数、最大高度、最小高度和工艺可行性。

## 7. 第四阶段：从圆形扩展到形状和角度

在多半径、多高度之后，可扩展到：

```text
随机旋角椭圆微岛；
短条形微岛；
短弧形微条；
圆形 + 椭圆混合；
圆形 + 短条混合。
```

预期作用：

```text
椭圆随机旋角：
增加方向去相关，避免单一圆岛频谱过于均匀。

短条形 / 短弧形：
可针对特定方向星芒或条纹做方向性削弱。

混合形状：
提高图案自由度，降低单一 primitive 造成的设计瓶颈。
```

风险：

```text
形状越复杂，mask/压印 master 数据量越大；
尖角或高纵横比结构可能增加制程和 haze 风险；
规则方向偏置可能引入新的方向性衍射。
```

## 8. 第五阶段：从 DOE 到 MATLAB 优化算法

后续如果 DOE 已经找到合理参数窗口，可以考虑调用 MATLAB 优化算法。

可选算法：

```text
patternsearch：
适合无梯度、非光滑目标函数。

ga：
适合离散变量、组合变量、多局部最优情况。

particleswarm：
适合连续变量的全局搜索。

surrogateopt：
适合单次仿真成本较高的黑箱优化。

fmincon：
适合连续变量和可微/近似平滑目标，但不适合直接优化 seed。
```

当前问题包含随机 seed、离散半径集合和 FFT 黑箱仿真，因此优先级建议：

```text
DOE -> Pareto 筛选 -> patternsearch / surrogateopt -> ga
```

不建议一开始直接使用 `fmincon`，因为图案生成和局部峰指标都不是光滑函数。

## 9. 第六阶段：Pareto 前沿

最终不应只输出单个最小 `Objective`，还应输出 Pareto 前沿：

```text
横轴：HazeRisk
纵轴：TopKPeakRatio
颜色：PeakBackgroundRatioPenalty 或 Objective
```

理想候选位于：

```text
TopKPeakRatio 较低；
HazeRisk 较低；
PeakBackgroundRatioPenalty 较低；
不同 seed 下表现稳定。
```

这类候选比单纯 `Objective` 第一名更适合进入样品 DOE 或专利实施例。

## 10. 后续代码建议

建议保持两个脚本分工：

```text
OptimizeMultiRadiusPhaseIslands.m
负责 DOE、目标函数、排序、保存结果。

CustomApertureWithPhase_fraunhofer_fft.m
负责将某个候选设计导入后，生成相位 map、3D 图、Figure 7/8/9 和峰值强度对比。
```

后续可以新增辅助函数或脚本：

```text
ApplyBestPhaseDesignToVisualization.m
从 CSV/MAT 中读取指定排名的候选设计，自动写入或传参给可视化脚本。

PlotPhaseDoePareto.m
读取 DOE 结果，绘制 HazeRisk vs TopKPeakRatio 的 Pareto 图。

CompareTopPhaseCandidates.m
批量导入前 N 个候选，生成 Figure 7/8/9 对比。
```

当前最重要的下一步是：

```text
先跑 full DOE；
检查 Objective 前列候选的 HazeRisk；
筛选 haze 风险受限的候选；
将 2~3 个候选导入可视化脚本；
比较 Figure 7/8/9 和峰值强度比例。
```
