# 非均匀高度示例与反射评价指标

本文记录引入 D65/nk 之前的三波长示例。复现时请设置 `spectrumMode="RGB"`、`cfg.materials.enabled=false`，保留 0.60/0.01 的强度反射率。当前默认光谱和材料参数已更新，不能直接复用下表作为新配置的结果。

## 示例与运行条件

2026-11-12，MATLAB R2024a。运行 `src/COEReflection_main.m` 的默认配置：16×16 个材料周期，每周期 32 点，512×512 计算面，FFT 补零倍数 4，输出 401×401，观察窗口 ±6°，评价圆锥半角 2.5°。

示例为覆盖整个反射面的 0/687.5 nm 二值条纹，周期 12.5 μm，占空比 50%，沿 x 交替。材料区域、0.60/0.01 的示例强度反射率和 Δn=0.20 保持不变。可通过 `useHeightExample` 开关启停；文件输入优先。

高低区双程相位差为 `4*pi*deltaIndex*height/lambda`。620/550/450 nm 分别约为 0.887π/1.000π/1.222π。以 550 nm 为参考，高度相位使零级发生接近相消的干涉。

## 默认配置的实际结果

下表的零级占比和锥外占比都以总反射能量为分母，单位 %。箭头表示“不叠加高度相位 → 叠加高度相位”。

| 波长 | 零级能量占比 | 2.5° 半角圆锥外能量占比 | ±6° 窗口捕获比例 |
|---|---|---|---|
| 620 nm | 39.734 → 1.2534 | 11.017 → 84.487 | 97.033% → 83.973% |
| 550 nm | 39.756 → 0.017302 | 9.8151 → 79.837 | 97.768% → 84.254% |
| 450 nm | 39.734 → 4.6632 | 6.6734 → 33.562 | 98.589% → 89.345% |

两种状态的总反射率均约 8.4326%（相对于入射能量），符合当前纯相位调制不改变反射振幅的模型。绿光零级的绝对反射率约由 3.3525% 降为 0.001459%；绿光锥外的绝对反射率则由 0.82767% 升为 6.7323%。纯相位调制将能量转移到其它方向，并没有使总反射能量减少。

远场和 RGB 图中可看到中心变弱、左右出现分离的彩色衍射结构。条纹一级偏转按近轴 `lambda/period` 估计，RGB 分别约为 ±2.84°、±2.52°、±2.06°，所以三种颜色跨越 2.5° 评价边界的程度不同。550 nm 一级恰好靠近边界，因此固定角度指标对阈值和采样较敏感，应检查采样收敛，不能将这个例子作为优化方案。

叠加高度后显示窗口只捕获约 84%～89% 的反射能量。锥外指标采用全 FFT 能量作为分母，包含显示窗口外的贡献；显示窗口中看不到的能量也没有从分母中丢掉。全 FFT 能量仍是标量近轴采样模型中的总量，不代表已模拟真实全半球电磁散射。

输出在 `Output/`：`coe_reflection_diffraction.png` 包含逐波长和 RGB 对比，`coe_reflection_metrics.png` 包含零级与雾度评价曲线，`coe_reflection_comparison_metrics.csv` 保存数值。

## 与标准反射雾度的差别

当前评价值为 `100*E_outside_cone/E_total_reflected`，用于描述能量从镜面反射附近向外分布的程度。它不是标准仪器的反射雾度。

ASTM D1003 对应透明材料的透射雾度，使用相对入射方向 2.5° 的阈值，见 [HunterLab：Measuring Haze](https://support.hunterlab.com/knowledgebase/article/KA-06011/en-us)。反射雾度使用另一套测量几何。例如 Rhopoint 对 ASTM E430 的实现是在 20° 镜面角附近的规定区域收集光，并有光度响应与补偿要求，见 [Rhopoint IQ 使用说明](https://www.rhopointinstruments.com/wp-content/uploads/2023/10/rhopoint-iq-manual-english.pdf)。当前法向入射模型没有复现这些仪器条件。

## 适合反射衍射方案评估的指标建议

下面是针对本项目的建议，不是另一套雾度标准。先确定目标是降低镜面眩光、抑制彩色衍射，还是降低整个观察范围内的反射干扰。

| 指标 | 回答的问题 | 建议用法 |
|---|---|---|
| 总反射率 `E_reflected/E_incident` | 总共反射多少光 | 与方向性指标一起报告；当前表已提供 |
| 指定接收视锥内的绝对反射率 `E_view/E_incident` | 观察者或探测器实际接收到多少反射光 | 按真实视角和接收孔径设置，作为任务主指标；现有零级绝对反射率是一个特定角域实例 |
| 非目标角域绝对反射率 `E_stray/E_incident` | 有多少能量形成不希望出现的光晕或衍射像 | 定义排除镜面主瓣及目标区域后的角域；固定 2.5° 锥外绝对反射率只能作为其中一种定义，当前表已提供 |
| 累计角能量曲线 `E(theta<alpha)/E_incident` 与二维角分布 | 能量移到哪里，是否存在方向性亮斑 | 比一个角度阈值更完整；指定角域或环带可直接从当前能量数组积分 |
| 非零级峰位置、有限接收角内能量与亮度 | 是否出现明显重影、彩色衍射斑 | 在相同光谱、角分辨率与接收孔径下比较；不要把随网格变化的单个 bin 峰值当成稳定的物理量 |
| 随视角的色度偏移 | 是否存在彩虹或彩色反光 | 需要光源光谱、更多波长采样与 CIE 配色函数；现有三波长增强 RGB 只能作定性预览 |

显示反射需要角度分辨的描述。NIST 指出，仅将显示反射写成理想镜面与 Lambert 漫反射的组合也可能不足以描述显示器；BRDF 更适合表征这类角度特性，见 [Display Reflectance Model Based on the BRDF](https://www.nist.gov/publications/display-reflectance-model-based-brdf)。当前 `spectralEnergy` 是每个输出角度 bin 的积分能量，不应直接改名为 BRDF。要与仪器或真实观察条件对齐，还需考虑入射角、偏振、光源角尺寸、光谱与接收孔径。接收孔径对散射比较的重要性参见 [NIST：Computation of Light Scattered Into Detector](https://www.nist.gov/publications/computation-light-scattered-detector)。

当前阶段建议以“绝对反射率 + 角度分布 + 彩色衍射特征”为组合，而不是只优化零级保持率或锥外占比。此示例恰好说明：零级降低很多的同时，非零级和彩色反光可能更突出。
