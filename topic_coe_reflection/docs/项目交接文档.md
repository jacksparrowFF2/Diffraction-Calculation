# COE 反射衍射项目交接文档

更新时间：2026-11-12。目标是在另一台电脑继续开发同一模块，而不依赖当前聊天记录或原电脑路径。

## 1. 项目定位与已确认要求

Diamond 图案化阳极/BM/RGB CF 多层结构已接入主脚本并默认启用可调示例。尤其注意“阳极外、BM 外扩开口内”的环带属于吸光底层，不是阳极。完整约定见 [简化 COE 多层模型约定](简化COE多层模型约定.md)。真实图样、材料 n/k 和厚度仍待用户提供；默认数据是演示占位。

- 主入口必须是从上往下可读、可运行的 `.m` 脚本，展示输入、参数、计算、展示和保存；具体算法保留为函数，并提供中文注释。
- 每次运行初始化工作区、命令窗口和旧图窗，但不重置搜索路径。
- 当前**默认高度是 0 nm，不添加额外高度相位**。非均匀高度条纹仅作为关闭状态下的可选演示。
- 两个比较状态是同一结构“不叠加额外高度相位 / 叠加额外高度相位”，不是运行过程中修改了材料设计，也不等于“无相位 / 有相位”。
- 方向性评价逐步建设：绝对角域反射率、累计角能量、非零级光斑位置及积分能量、随角度色度分布。
- 显示增强应使用共同参数并尽量保持色度；物理指标必须基于原始数据。

## 3. 关键物理和数值约定

1. `spectralEnergy(:,:,k)` 是相对于该波长入射能量的每个输出 bin 积分能量，不能当作未积分强度密度，也不能直接命名为 BRDF。
2. 复系数是振幅；强度为模平方。优先级：外部复系数 > 启用的多层模型 > 旧单界面 n/k > 旧强度反射率模型。regionMap 的 bit0 为阳极、bit1 为 BM，整数除以4为 CF 标签0/R/G/B；查表行号为编码+1。
3. 额外高度相位使用 `4*pi*deltaIndex*h/lambda`，默认 h=0。膜厚相位及到共同空气参考面（BM厚度+最大CF厚度）的相位另行计入，不应重复加进 heightMap。局部柱体假设 CF 开口内从裸底起算，在 BM 上则叠加在 BM 顶面。
4. 波长非相干叠加。D65 辐射度权重含波长积分宽度且总和为 1；XYZ 三分量共用 Y 归一化常数，不能分别做 RGB/XYZ 通道归一化。
5. `OutsideAngleFraction` 以模型 FFT 总反射能量为分母，包含输出窗口外贡献；观察角域、累计曲线和光斑 ROI 只对窗口内数据积分。
6. 角域使用输出 bin 中心判定。靠近边界的光谱峰或光斑 ROI 应进行物面、FFT 补零、输出角网格、光谱步长的收敛检查。
7. 光斑用两个状态共同参考图定位，然后回到各状态原始能量积分；圆之间不重叠，不能将增强图用于检测或统计。S 编号不是理论衍射阶数。
8. 共同自动曝光仅保证一次比较的两状态可比；跨多个设计应记录或固定曝光。显示增强不改变 `XYZ/xy`；`displayXYZ/displaySRGB` 是另存的显示结果。
9. BM/CF 材料 n/k 暂为常数示例，也可读 CSV/向量；真实 CF 必须提供色散吸收谱。吸收终端裸底 r=0、阻抗匹配入射介质，覆盖膜后的界面反射仍计算。D65 仅覆盖380–780 nm；反射雾度是代理，不是 ASTM E430 读数。

## 4. 当前默认参考值与验收

已验证环境为 Windows / MATLAB R2024a，默认材料 n/k、512×512 物面、81 波长、0 nm 高度。历史参考值：

- D65 积分白点 xy ≈ (0.31272, 0.32904)。
- 多层示例总辐射反射率 ≈ 9.93634%，总明视觉反射率 ≈ 9.89988%。
- 中心半角 2.5°观察圆内：辐射度绝对反射率 ≈ 8.78640%，明视觉 ≈ 8.63085%。
- 旧 simple 单界面配置的 4.52816% 总反射率仅用于历史对照，不是当前多层默认值。
- 两种高度状态的原始光谱能量、色度、累计曲线和光斑表应相同。
- 非零级表数值应按角坐标及积分半角核对；对称峰编号可能因浮点误差调换，不以 S 号作为跨计算永久标识。

直接复制完整模块或从 Git 拉取即可，不需要迁移 ZIP。`Output/` 默认不纳入 Git，当前计算结果保留在原电脑；需要同一批原始数据时另行复制 MAT，或在新电脑重新运行生成。

## 5. 验证与继续开发

完整仓库包含 `tests/COEMultilayerTest.m`、`COESpectralTest.m`、`COESpotsTest.m`。多层测试覆盖裸底极限、共同相位面、四分之一波膜、独立特征矩阵、无损镜背守恒、厚吸收极限、阳极面积、图样导入、n/k CSV及CF覆盖/交叠；其它测试覆盖光谱、色度、角域和光斑积分。

`tests/ModuleIsolationTest.m` 的 COE 分支验证复制后的主脚本、多层默认、文件输入、默认零高度、旧三波长及 D65 图表输出。完整仓库中可运行：

```matlab
suite = matlab.unittest.TestSuite.fromFile('tests/ModuleIsolationTest.m','Name','*coe*');
r = run(suite);
assert(all([r.Passed]));
```

建议后续工作按以下顺序推进：

1. 用真实 Diamond 图样及 n(lambda)/k(lambda)/厚度替换示例，确认实际 CF 填充/平坦化剖面与吸光底层参数，取代当前理想终端和局部柱体假设。
2. 为光斑增加手动指定 ROI 或已知衍射阶次跟踪，避免强相位或宽带彩色带状结构下完全依赖局部峰自动检测。
3. 增加各方向截线、环带能量和区域色度随观察角度曲线；继续保留 D65 辐射度与明视觉两种定义。
4. 增加有限尺寸光源、入射角、偏振和接收孔径，以接近实际仪器或观看场景；需要对标标准反射雾度时单独实现相应测量几何与校正。
5. 对最终产品参数做收敛及实验比对；不要把目前默认演示数据或增强图当成真实产品结论。

## 6. 另一台电脑的交接流程

1. 从远端检出本次分支，或直接复制整个模块到可写目录；保持 src/private 和 Input/Colorimetry 层级。
2. 需要算法验证时同时保留仓库 tests，使用 MATLAB runtests；不依赖 Codex/MCP。
3. 打开主脚本，核对 multilayer、Diamond 示例、额外高度 0、D65、BM 外扩及材料示例值。
4. 完整运行，确认参考值和五个图窗，并检查输出 CSV 的字段和单位。
5. 另存工作副本或建立 Git 仓库后再修改。每次不同参数建议使用新的 `caseName`。
6. 将后续发现、参数依据和未完成事项写入本文件，避免只保存在聊天记录中。

无需复制 MATLAB 安装、账户配置或原电脑 MCP 配置；本次提交不包含迁移 ZIP。
