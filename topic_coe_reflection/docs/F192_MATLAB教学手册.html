01 · 先恢复 MATLAB 的操作感

这一步解决什么问题

MATLAB 同时有“文件”和“当前内存”。磁盘上的脚本并不等于已经运行；工作区里的变量也不一定来自刚打开的脚本。先分清两者，能避免拿旧变量解释新结果。

界面区域做什么本次怎样使用
当前文件夹 / Current Folder查看磁盘文件，决定相对路径起点定位 topic_coe_reflection/docs 或 src
编辑器 / Editor编辑并运行 .m 文件打开 f192_tutorial_lab.m；先读注释再运行节
命令窗口 / Command Window输入短命令，查看输出与错误输入 pwd、whos、size(labA)
工作区 / Workspace查看已存在于内存的变量双击 labA 查看 2×3 数组
图窗 / Figure查看绘图看图时检查坐标、单位、显示映射
pwd                            % 显示当前文件夹，不修改它
cd('D:/03 Optical Simulation/Diffraction-Calculation/topic_coe_reflection/docs')
open('f192_tutorial_lab.m')      % 在编辑器打开练习
whos                           % 列出变量名、尺寸、类型、占用字节
help reshape                   % 简短帮助；doc reshape 打开更完整文档

路径使用引号包围，空格便不会把路径拆成几段。Windows 的 MATLAB 路径中可使用正斜杠。若项目已移动，改成你电脑上的实际目录。

脚本中的 %% 把文件分为“节”；选中一节后点击编辑器的“运行节”，适合逐步观察。% 后面是注释，不执行。行末 ; 只抑制打印，不抑制计算。... 表示语句续到下一行。运行整个文件用编辑器“运行”，通常为 F5；快捷键可能随平台设置变化，按钮更可靠。

脚本与函数

COEReflection_main.m 是脚本，会在当前工作区创建和修改变量。runCOEReflection(cfg,stack,inputDir) 是函数，参数是入口、返回值是出口，内部临时变量通常留在自己的工作区。函数第一行的 function result = ... 表示把计算结果装进 result 返回；arguments 块检查参数类型与尺寸。

正式 main 开头有 clearvars; clc; close all;：依次清理当前变量、命令窗口文本和图窗。先保存自己的工作，不要将它当成“只打开文件”。main 还会保存输出，同名结果可能被覆盖。

检查：运行练习第 1 节后，工作区应出现 labA、labCube 等变量。若只打开文件而未运行，工作区不会自动出现这些变量。遇到错误先看红字第一条错误和对应文件行号，不要反复点运行。

02 · 每个变量、数组和运算符在做什么

从一个数到一个光谱立方体

pitch = 59.06e-6;          % 1×1 double，科学计数法：59.06×10^-6 m
periods = [4 4];           % 1×2 行向量，[x方向Pitch数, y方向Pitch数]
lambdaNm = (380:10:780).'; % 41×1 列向量；从380开始，每次加10，到780
cfg = struct();           % 结构体：带名称的容器
cfg.pitch = pitch;        % 点号访问字段
cfg.source.type = "plane"; % 可嵌套字段；双引号表示字符串
enabled = true;           % logical，逻辑真；false 为逻辑假
emptyValue = [];          % 空数组，通常表示未提供可选输入

上面是语法演示，不会自动读取配置。double 是本次主要浮点类型，每个实数通常 8 字节；logical 用来表达覆盖/不覆盖。cfg 结构体把参数按名字组织；table 则适合每行一个波长、每列一种指标的异类数据，例如 T.Throughput 返回一列数。

% 教学例子，不是 F192 的实际光学数据
A = [1 2 3; 4 5 6];       % 2行×3列
A(2,3)                    % 第2行第3列 = 6；MATLAB 索引从1开始
A(:,2)                    % 所有行、第2列 = [2;5]
A(1,:)                    % 第1行、所有列 = [1 2 3]
A(:)                      % 按列展开 = [1;4;2;5;3;6]
E = reshape(1:24,2,3,4);   % 2×3×4，第三维当作4个波长
s = squeeze(E(2,3,:));     % 1×1×4 → 4×1：[6;12;18;24]
w = [0.1;0.2;0.3;0.4];    % 4×1
F = reshape(E,[],4);       % 6×4；每行是一位置，每列是一波长
imageValue = reshape(F*w,2,3); % (6×4)*(4×1) → 6×1 → 2×3
imageValue(2,3)            % 6*0.1+12*0.2+18*0.3+24*0.4 = 18

reshape 只重排形状，不增减元素、不插值；[] 让 MATLAB 推算那一维，乘积必须等于元素总数。MATLAB 按列存放，故每个波长页展开顺序一致。squeeze 删除长度为 1 的维度；用于单像素光谱很方便，但一般代码仍要用 size 检查结果形状。size(E,3) 是波长数，numel(E) 是所有元素数。

写法意义本次用途
A*B矩阵乘法，内维必须相同位置×波长 乘 波长×XYZ
A.*B对应元素相乘；允许兼容尺寸扩展同一物面位置入射场乘局部反射系数
A./B、A.^2逐元素除法、平方每像素归一化、强度计算
A/B、A^2矩阵除法、矩阵幂；标量情况可与逐元素相同不要拿它们代替两个一般矩阵的逐元素运算
A.' / A'前者仅转置；后者共轭转置处理复场时不能随意互换
A>0、&、~比较、逐元素逻辑与、逻辑取反产生材料掩膜或 ROI
= / ==赋值 / 判断相等cfg.pitch=... 设置；name=="F192" 筛选

复数与单位

复振幅 r = a*exp(1i*phi) 有幅值 a 和相位 φ。1i 是虚数单位，避免变量 i 被循环索引覆盖。abs(r) 是模，angle(r) 是相位（rad），real(r) / imag(r) 取实/虚部。强度反射率 R=|r|²。例如 R=0.25、φ=π 时，r=−0.5，不能用 r=0.25 替代。

长度运算统一 m：1 μm=10⁻⁶ m，1 nm=10⁻⁹ m；角度内部 rad，deg2rad(5) 将 5° 变为约 0.0872665 rad，rad2deg 反向转换。变量名带 Deg/Nm 是很有用的单位提示。数组里的值本身不会自动带单位。

自检：若 E 是 1801×1801×41，则 E(:,:,18) 是 1801×1801 的 550 nm 图；E(901,901,:) 是 1×1×41；reshape(E,[],41) 是 3,243,601×41。不能用 sum(E(:)) 冒充 D65 宽带积分，因为波长权重尚未使用。

04 · 六张 PNG 怎样变成 256×256 的物面

输入、阈值与反转

六层原图都是 1000×1000，代表同一 4×4 Pitch 物面，每 Pitch 250 点。每张图表示一个层的横向覆盖，不表示高度，不是 RGB 发光强度，也不是照片。所有层必须共用尺寸、坐标原点与方向；分别裁切一张图会破坏对齐。

% 教学版二值化流程：解释源码步骤，不对输入写回
raw = uint8([0 127 128 255]);
gray = double(raw)/255;       % uint8 的0~255转换为0~1
mask = gray > 0.5;           % [false false true true]，严格大于
inverted = ~mask;             % [true true false false]
% 正式源码若读到RGB三通道，用 mean(value,3) 求平均后再阈值化

threshold=0.5 先决定哪一侧是白；每层的 invert 再决定材料覆盖。F192 的 IJP 原图全黑、invert=true，因此最终整面覆盖；BM 也显式 invert=true。不要只凭黑白视觉判断“黑色一定是材料”。查看 sampled_geometry 中 1/白才是最终模型覆盖。

尺寸计算，一步不跳

Lx=Ly=4×59.06 μm=236.24 μm
Nx=Ny=4×64=256
dx=dy=59.06/64 μm=0.9228125 μm
原图间距=59.06/250 μm=0.23624 μm
Ainc=(236.24×10⁻⁶)²=5.58093376×10⁻⁸ m²

inputSamplesPerPeriod=250 明确原图采样；samplesPerPeriod=64 明确计算采样。源码在内存按共同像素中心最近邻抽样，形成每层 256×256 logical；原图没有改写。最近邻保留二值，不产生灰边；减少采样可能丢失细线或改变面积，因此 64 点/Pitch 是本次工作设置，不是连续几何已收敛的证明。

第2章已介绍索引，这里可以看实际抽样公式：rows=floor(((0:255)+0.5)*1000/256)+1，列也同样计算。floor 向下取整，最后 +1 转成 MATLAB 下标；最前几个原图下标是 2、6、10、14，最后一个是 999。六层共用同一组 rows/cols，不能分别“寻找最佳对齐”。教学阈值例子中 [0,127,128,255]/255 在严格 >0.5 后为 [0,0,1,1]；invert=true 再变成 [1,1,0,0]。

repeatToFit/cropToFit/pixelReplication 是显式几何规则，不应理解为“任意图片自动变成高精度”。本次原图和目标都代表每轴 4 Pitch，关键变化是 250→64 的抽样，不需把 4×4 原单元扩成更多周期。像素复制即使放大数组，也没有增加原图几何信息。传播坐标约定以零点居中的采样网格为准；图层抽样保持共同像素中心对应，不要自行给某一层平移半像素。

检查：各层 256×256；IJP 应全覆盖；叠图时同一坐标仍对齐；sum(mask(:))/numel(mask) 是该层面积占比。面积相似也不保证边缘位置相同，应结合轮廓检查。正式 区域表面积分数之和应为 1。

05 · 从覆盖图到每个位置的复反射系数

为什么不能把六张图直接相加

同一横向像素可能同时有 IJP、BM 与 CF。它是一根从下到上具有多层材料的“局部柱体”，需要先算该柱体的复反射系数 r(x,y,λ)，再用于横向衍射。把材料反射率按面积直接相加会丢失层间干涉和反射相位。

从下到上本次光学定义厚度
1 Anodereflectance 有效不透明反射边界，R=1、phase=180°，r=−1；不将其当成透明有限膜0（有效边界定义）
2 IJPn=1.5，k=0，整面覆盖10 μm
3 BMMaterials/BM_nk.csv 插值1 μm
4 CF_RMaterials/CF_R_nk.csv 插值1.1 μm
5 CF_BMaterials/CF_B_nk.csv 插值0.9 μm
6 CF_GMaterials/CF_G_nk.csv 插值1 μm

以上是独立物理层级，重叠处保留各层膜厚，不强制三色互斥。同一物理层级的材料才要求互斥。光从上方入射，递推算法接收的有限膜列表是从上到下，与 config 的从下到上声明相反；源码 fliplr 完成这个转换。

n+i·k 是什么

N=n+iκ，传播因子 exp(i·2πNd/λ)
= exp(i·2πnd/λ) × exp(−2πκd/λ)

这里用 κ 区分消光系数和波数。n 影响相位，κ≥0 导致振幅随传播距离衰减；厚度 d 同时影响相位与衰减。法向界面振幅系数 r_ab=(N_a−N_b)/(N_a+N_b)；多次往返相干叠加形成薄膜干涉。透明 IJP 的 κ=0 只表示体内无此吸收，仍有折射率界面与光程。

reff = rinterface + rbelow · exp(4πiNd/λ)1 + rinterface · rbelow · exp(4πiNd/λ)
查看纯文本公式r_eff = (r_interface + r_below·exp(4πiNd/λ)) / (1 + r_interface·r_below·exp(4πiNd/λ))

该式把一层膜及下方等效反射合并；指数中的 4π 是往返光程。底层有效边界还需要转换到邻接膜的阻抗参考，源码不是盲目把 r=−1 塞进任意界面。各局部柱体高度不同，程序补齐到共同空气参考平面的往返相位，确保横向相位可以比较。

教学例子：IJP 单程光程 n·d=15 μm，550 nm 的往返相位=4π×15/0.55≈342.72 rad。即使 heightMap=0，这个膜厚相位依然存在；膜堆返回的 r 已经包含它。均匀额外高度只乘全局相位，不改强度；空间变化的高度才重新分配衍射。

区域查表，避免重复算相同膜堆

每位置用六个布尔值表示材料组合，例如正式 RegionCode=10 的 [Anode,IJP,BM,CF_R,CF_B,CF_G]=[1,1,0,0,0,1]，面积分数约 0.05917358，局部厚度 11 μm。只对实际出现的组合求 r(λ)。本次有 13 个区域，regionMap 是 256×256，coefficientLookup 是 13×41。存储区域编码从 0 开始，但 MATLAB 查表索引从 1 开始，需要 code+1；初学者不要把编码直接当数组下标。

n+iκ、界面和相干递推各负责什么

材料复折射率写成 N=n+iκ，这里的 κ 就是材料 CSV 的 k，别与波数 2π/λ 混淆。n 决定相位传播速度，κ≥0 描述传播衰减。法向两介质界面的复振幅系数为 r_ab=(Na−Nb)/(Na+Nb)。教学例子：空气到 n=1.5、κ=0 的介质，r=−0.2，|r|²=0.04。因此透明 IJP 仍有界面反射。

pⱼ=exp(4πiNⱼdⱼ/λ)
r有效=(r界面+r下方·pⱼ)/(1+r界面·r下方·pⱼ)
pⱼ=exp(4πinⱼdⱼ/λ)·exp(−4πκⱼdⱼ/λ)

d 是膜厚（m），p 是穿过该膜往返一次的复振幅因子。第一个指数贡献往返相位，第二个贡献振幅衰减；强度衰减还要取模平方。分母体现层间多次反射的相干求和。算法从最底端反射边界向上逐层递推；输入膜列表则从入射侧往下排列，故声明的从下到上层序会在准备阶段反转。

不同柱体顶部不齐时，代码补足到同一个空气参考平面的往返相位 exp(4i*pi*incidentN*airGap/lambda)。若每根柱体各自把顶部相位设为0，会改变柱体间的相对相位与衍射。本次上层透明膜、BM和CF都参与局部复数运算；heightMap=0 不删除这些项。模型输出是每位置每波长 r，概念形状256×256×41；传播中可以从区域表按波长取一页来使用。

外部背景是 absorber 匹配终端，意味着进入终端的光不返回；覆盖膜仍可能产生界面反射。Anode 不透明边界遮蔽其下方光学堆，不是额外再叠一个 n/k 阳极。只用局部反射数据不能将所有“未返回”无条件解释为材料吸收，尤其切换 medium 出射介质时还可能有透射。

输出与检查：r 的概念形状是 256×256×41，但实现可逐波长从区域查表取出二维系数；检查 abs(r)≤1、值有限、材料 CSV 覆盖 380—780 nm、厚度与配置一致。不能把反射相位 angle(r) 当成反射率。

07 · 为什么要傅里叶积分，FFT 在哪里

从波的叠加到远场

每个物面位置都向远处贡献一个波。观察方向改变时，不同位置到观察点的光程差改变，叠加相位也改变。近轴夫琅禾费模型把该光程差写成与 x、y 成线性的相位，因此方向分布就是物面复场的傅里叶积分。

F(fx,fy)=∫∫ u_ref(x,y) exp[−2πi(fx·x+fy·y)] dxdy
fx=θx/λ，fy=θy/λ
U(θx,θy)=exp(2πiz/λ)/(iλz) · F(θx/λ,θy/λ)
I/Iinc=|U|²；X≈zθx，Y≈zθy

这里 θ 用 rad，fx/fy 单位 m⁻¹。离散积分就是所有物面采样点乘相位后求和，再乘 dx·dy；输出复场模平方得到强度。当前函数省略接收面二次相位，因为只需远场强度；这不表示它已经成为保留全部相位的有限距离成像模型。

为什么不是随手 fft2 然后画图

普通 N 点 FFT 自带离散频率间隔约 1/(N·dx)=1/L，相应角步长 λ/L，会随波长改变。本次要求所有 λ 共用 ±5°、1801 点角网格，不能把各波长原生 FFT 格点直接叠在一起当相同角度。生产函数 corePropagateReceiver 使用 chirp-convolution，在指定均匀频率网格上计算傅里叶求和。

离散核中的 n·m = [n²+m²−(m−n)²]/2
交叉相位 → 输入二次相位 × 差分二次相位卷积 × 输出二次相位
卷积通过 ifft(fft(输入)·fft(卷积核)) 加速

“chirp”指二次相位序列；这里它是傅里叶计算的代数重写，不是添加一种真实光学元件，也不是换用 Fresnel 传播。源码先沿一轴 transformColumns，再沿另一轴，合起来得到二维积分；乘 step 两次对应 dx·dy。零填充用于避免卷积绕回，并不增加原始版图信息。

输出像素是一个 bin，不是数学点

Δθ=10°/1800=0.00555556°≈9.6962736×10⁻⁵ rad
ΔΩ≈Δθ²≈9.4017722×10⁻⁹
ΔA_receiver=(zΔθ)²≈5.8761076×10⁻¹⁰ m²
Ebin=平均(I/Iinc)·ΔA_receiver/Ainc

函数对每个输出 bin 内再作细分中点积分，cfg.receiverBinSamples=3 是每轴最少点数。为避免窄峰漏积分，细分数还取不小于 ceil(4*extent*Δθ/λ)，并调整为奇数。本次参数下 3 已满足该要求；具体以保存的 receiverSamplesPerBin 为准。输出点数变多不会自动改变物面采样，也不能靠把窗口能量重新归一化为 1 来“补回”窗外能量。

角度和毫米如何对照

550 nm 时，名义周期衍射间隔 λ/Pitch=0.00931256 rad=0.53357058°；z=0.25 m 时 X≈0.25×0.00931256=0.00232814 m=2.32814087 mm。本次主轴检测亮斑约 ±0.52777778°，受有限孔径、光谱、图样和离散网格影响，不宜把所有检测斑直接命名为理论某级次。

检查：中心索引是 (1801+1)/2=901；0.5° 在接收面约 2.18166 mm，计算必须先 deg2rad。使用 z·tanθ 属于另一几何表达，不能只更换坐标却仍声称数值严格等同当前近轴模型。

08 · 守恒检查通过，为什么仍要讨论误差

Parseval 检查的是哪件事

傅里叶变换前后的总平方模在相应归一化下相等。程序另算原生离散 FFT 全频域能量，比较它与物面 sum(abs(field(:)).^2)/incidentEnergy，导出 ParsevalAbsoluteError。本次 F192 最大误差约 2.18×10⁻¹⁴，说明离散变换的归一化守恒一致。

Parseval 很小不能证明材料数据正确、64 点/Pitch 几何足够细、10 nm 光谱足够密、25 cm 严格处于远场。它也不要求 ±5°窗口捕获 100% 的反射光。
误差/限制来源本次情况应怎样理解或后续验证
物面抽样dx=0.9228125 μm；最短 λ=380 nm 的近轴 Nyquist 角约 λ/(2dx)=0.2059 rad±5°通过带宽条件；这不保证二值边界已收敛，需单独 raster 扫描
有限 4×4 Pitch峰有有限宽度；550 nm 中心 FWHM≈0.12103813°增加周期数通常使峰更窄；总量和峰高/形状需分别比较
输出采样/ROI 边界1801点，bin 内积分；圆域按 bin 中心选择边界小幅偏移可能改变积分；必要时比较输出网格收敛
厚膜光谱10 μm IJP；诊断最大往返相位步进约 18.59 rad10 nm 可能漏过快速干涉振荡；本轮没有光谱收敛保证
远场近似用全边长 L 定义的 L²/(λz)，最短波长约 0.5875不是远小于1；25 cm 有模型误差风险，不能宣称严格远场已验证
局部标量膜堆法向、逐柱体相干膜堆，再标量近轴传播未完整求解横向电磁耦合、边缘散射、粗糙度或偏振角依赖
颜色与外观D65/CIE 色度 + 显示映射不是相机曝光、镜头、传感器或完整人眼视觉模型

此处的远场数采用项目诊断的全边长约定；有的教材用半宽，数字会差 4 倍，比较时先统一定义。本手册如实复盘这次参数，不为教学静默换算法、加光源或重跑更大仿真。

09 · 41 个波长如何变成 XYZ 三个分量

先把光谱权重说清楚

D65 是标准照明体的相对光谱功率分布 S(λ)，不是“每波长一样亮”，也不是把三个波长直接设为 R/G/B。CIE 三条配色函数 x̄、ȳ、z̄ 将光谱映射到标准观察者的 XYZ；其中 ȳ 对应本模型使用的明视觉视见加权。只用 ȳ 能得到 Y，不能得到完整颜色。数据定义可参见 CIE 官方配色函数。

连续积分用离散梯形求和近似。380:10:780 有 40 个间隔、41 个点：端点积分权重 5 nm，内部 10 nm。这里端点半权重不是把首尾波长的反射率减半，而是数值积分规则。

q=[5,10,…,10,5] nm；aₖ=Sₖqₖ
wEₖ=aₖ/Σaₖ；wYₖ=aₖȳₖ/Σ(aₖȳₖ)
WXYZₖ,:=aₖ[x̄ₖ,ȳₖ,z̄ₖ]/Σ(aₖȳₖ)
[Xij,Yij,Zij]=Σₖ Eijₖ·WXYZₖ,:

wE 和 wY 各自和为 1，前者用于辐射度，后者用于明视觉。XYZ 三列共同使用 Y 的归一化常数，不能每列分别归一化，否则白点和颜色会被改掉。理想单位反射的 Y=1 是所选入射明视觉参考；当前 XYZ 不直接是绝对 cd/m²。

xyz = signals*spectrum.xyzWeights;% 3,243,601×3
XYZ = reshape(xyz,1801,1801,3);   % 第三维依次X、Y、Z
% 注意：E尚未乘D65；xyzWeights已含D65、梯形权重和配色函数

XYZDensity = XYZ/(coordinate(2)-coordinate(1))^2;

每 bin 的 XYZ 随 bin 面积改变；除 ΔΩ 后的 XYZDensity 便于在不同输出网格间比较角密度。它仍是归一化分布，不能未经实验标定直接称 BRDF。原始 Y 已在 XYZ(:,:,2) 中存在，曝光仅改变显示副本中的倍率。

x = XX + Y + Z　 y = YX + Y + Z
查看纯文本公式x=X/(X+Y+Z)，y=Y/(X+Y+Z)

小写 xy 表达色度比例，丢失总量；两个像素若 XYZ 成比例，xy 相同但亮度不同。黑像素分母为 0，代码保存 NaN，表示色度未定义。整个窗口的色度应先把窗口 XYZ 相加再求比例，不能直接平均所有像素的 xy；本次窗口 xy=(0.29474117,0.32040319)。

Throughput=Tₖ，CapturedThroughput=Wₖ，CapturedFraction=Wₖ/Tₖ，ZeroOrderFraction=Zₖ/Tₖ，OutsideAngleFraction=1−Cₖ/Tₖ。因此零级宽带入射反射率应是 dot(T.*ZeroOrderFraction,wE)，不是 dot(ZeroOrderFraction,wE)。百分号只是在最终乘 100，不能再把 CSV 中已有 Percent 的列乘 100。

观察圆、检测圆与理论级次

零级积分半径随 λ 变；固定 ROI 半径不随 λ 变，两者用途不同。亮斑检测先排除中心 0.30°，候选峰相对阈值 0.08，最小分离 0.35°，每组最多 8 斑；每斑用半径 0.15° 圆积分。diffraction_spots.csv 的 AbsoluteReflectancePercent 以入射为分母；它是局部能量，不是该点峰值。未被检测进前 8 个的斑也仍在物理数组中。

累计曲线 cumulative_energy.csv 是“以中心为圆心，半径逐渐增加”时圆内反射/入射。曲线应非减，不应把它当作每个环带的能量；环带能量等于两个累计值之差。曲线在半径 5°止步于内接圆，不等于 ±5°方窗，方窗还有四角。

总量、峰高与形状必须分别报告

把相同能量集中到更小的角域，峰可以更高、FWHM 可以更小，而总反射不变。FWHM 是中心峰过半峰高的左右交点宽度，本次 550 nm 水平截线约 0.12103813°。点阵形状相似也不意味着功率相同。不要用增强 PNG 的最大像素来替代物理总量，也不要用每图各自最大值归一化后比较绝对亮度。

做完再展开答案

1 · 256×256 从哪里来？物面面积是多少？

每轴4 Pitch×64点/Pitch=256；边长236.24 μm；面积5.58093376×10⁻⁸ m²。1000×1000是同一物面原图的采样，不代表更大的物理尺寸。

2 · heightMap=0，为什么颜色仍随波长变化？

材料n/k随波长变化，有限膜厚有往返干涉相位，衍射角尺度也随λ变。heightMap只关闭额外高度相位，不消除膜堆已有相位。

3 · 某波长T=0.1、ZeroOrderFraction=0.05，零级/入射是多少？

0.1×0.05=0.005，即0.5%。宽带时应逐波长先相乘，再用对应权重求和。

4 · 把E直接按第三维求平均，是否就是D65？

不是。D65各波长功率不同，端点还有梯形半权重；XYZ更要三条配色函数和共同Y归一化。用已保存权重，不能重复乘SPD或步长。

5 · 0.06609544 是曝光倍率吗？

在教学像素XYZd=(120,100,80)中，它是Ye=100g。g约0.00066095444。Y在曝光之前已经是XYZ第二分量。

6 · Parseval误差10⁻¹⁴，能否证明10nm光谱精确？

不能。Parseval核对离散变换的能量归一化；厚膜光谱可能漏采样，需另外做波长步长收敛研究。

7 · 窗口捕获91.13%，剩余8.87%是否吸收？

这是反射光中未落入±5°窗口的比例，属于窗外反射；不是入射能量的8.87%，也不能称吸收。

8 · 两张各自自动曝光的图看起来同样亮，是否反射率相等？

不能。各自曝光可能抵消物理强弱差异。比较反射率读CSV；比较相对显示亮度用相同gain和映射；比较色度用原始XYZ/xy。

进一步的小练习

在配套练习中分别改“教学像素”的Y尺度、EV和toneStrength，观察结果；不要改正式config。把教学权重改为均匀，解释与D65结果的差异。读取固定ROI表，检查半径增大时积分不下降。用 λ/Pitch 分别计算450、550、620nm的名义间隔，并解释彩色斑为什么错开。每次只改变一个量，写清楚它影响“物理响应”还是“显示”。
